Complete Login, To-Do List, and Responsive Cards Project
This project is a simple web application with a login page, a to-do list functionality, and a responsive card layout. It was developed using HTML, CSS, and JavaScript to showcase essential frontend development skills.

Features:
Login Page:

Users can enter an email and password.

The form validates the email format and password length before allowing submission.

After successful login, the user is redirected to the To-Do List page.

To-Do List Page:

Users can add, update, and delete tasks.

The tasks are not saved on reload (local storage is not used).

Responsive Cards:

The About Page contains three cards that are responsive to desktop, tablet, and mobile views.

On desktop, three cards appear horizontally. On tablet, two cards are horizontally aligned, and the third one is placed underneath. On mobile, all cards are displayed vertically.

Technologies Used:
HTML

CSS

JavaScript

How to Run the Project:
Clone the repository to your local machine.

Open the index.html file in a browser to view the project.

You can interact with the login form, add/update/delete tasks in the To-Do list, and view the responsive cards.
